# Asset and design notes

## Original hero image

- File: `dist/assets/hero.webp`
- Generated with the built-in Image Generation tool; optimized to WebP for this site.
- It is a concept residence, not a customer property, connected camera, or actual monitoring result.
- Final generation prompt:

> Create a premium architectural photograph for a smart home fire-monitoring website. Landscape 3:2 composition, photorealistic editorial architecture. A beautiful low contemporary two-storey house with black timber siding, warm limestone, large floor-to-ceiling windows glowing amber, dusk, muted grey sky, a single elegant olive tree, quiet landscaped garden with grasses. House occupies the center and right, strong sculptural rectilinear geometry, viewed from slightly elevated front three-quarter angle. Calm, safe, quietly luxurious, realistic materials, soft cinematic lighting. NO fire, NO smoke, NO people, NO text, NO logos, NO typography, NO graphics, NO UI overlays. Keep architecture readable with warm interiors. Palette warm grey, charcoal, natural green, amber, restrained. High quality photographic detail. This is the final hero asset for the FireCam website.

## Type and graphics

- Manrope, self-hosted from Google Fonts, weights 400–800. SIL Open Font License; see `dist/assets/OFL.txt`.
- The FireCam logo is the user-supplied `Unknown-removebg-preview.png`, copied unchanged to `dist/assets/firecam-logo.png`. App icons are proportionally resized, centered versions with transparent padding. Interface icons, floor-plan graphics, and decorative device frames were authored as SVG/HTML/CSS for this project.

## Design research

- [Awwwards: The F Suite](https://www.awwwards.com/sites/the-f-suite) — warm colour contrast, clear typography, responsive composition.
- [Awwwards: Invisible North](https://www.awwwards.com/sites/invisible-north) — visual rhythm, focused interactions, strong editorial hierarchy.
- [Awwwards: Mobile performance](https://www.awwwards.com/brainfood-mobile-performance-vol3.pdf) — mobile readability and performance considerations.

The design is original. It does not reuse Awwwards site code or claim an Awwwards award.
